## Как пользоваться (первый запуск)
1. Регистрация → онбординг (4 столпа, баланс, темп, цель, старт).
2. Карта: идти по узлам сверху вниз, переключатель «Основной путь /
   Кандзи» — два трека.
3. Урок = теория → практика (карточки). Всё показанное уходит в
   Повторение.
4. Повторение: вспомнить → перевернуть → честно оценить.
5. Статистика, Профиль, Настройки — в левой панели.

## Аудирование: японский голос Windows
Озвучка использует системный синтезатор. Для правильного японского:
Параметры → Время и язык → Язык и регион → добавить «日本語», в его
параметрах включить компонент «Речь». Без него экран аудирования
предложит читать вслух по ромадзи.
