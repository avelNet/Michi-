# План разработки Michi — от ~40% к рабочему приложению для изучения

Живой документ. Отмечать `[x]` по мере готовности. Каждый пункт —
отдельный коммит (или несколько), чтобы можно было откатиться.

## Что уже есть (стартовые ~40%)

- **Стек**: Flutter (десктоп, цель — Windows; каркасы Android/iOS есть),
  Dart, Drift/SQLite — локальная БД в `getApplicationSupportDirectory()`.
- **Схема БД** (`app/lib/data/schema.drift`, зеркало `db/schema.sql`):
  контент (кана, радикалы, кандзи, слова, частицы, грамматика,
  предложения, юниты + DAG предпосылок) и данные пользователя (users,
  user_profile, srs_cards, review_log, unit_progress, user_vocab,
  daily_activity, comprehension_snapshot).
- **Контент засеян**: вся хирагана+катакана (46+46), 2134 кандзи и 5139
  слов из открытых источников, 4 частицы N5, ~14 юнитов дорожной карты
  (кана ×2, кандзи+слова ×4 (только N5, 80 кандзи), частицы ×2 (наполнена
  только I), грамматика ×2 (**пусто**), аудирование ×2 (**пусто**), веха).
- **Экраны**: Дорожная карта (визуальный путь + сайдбар со статой),
  Урок (теория → практика: карточки-перевёртыши), Повторение (SRS,
  4 оценки), Справочник каны (сетка + деталь).
- **SRS**: упрощённый SM-2 с шагами заучивания, покрыт тестами.
- **Тема**: светлая/тёмная, палитра washi/ink, кастомные шрифты.
- **Пользователь**: один захардкоженный `localUserId = 'local'`, без
  входа, без онбординга. Тема не сохраняется между запусками. Серия дней
  (`currentStreakDays`) — заглушка `return 0`.

## Чего не хватает (задачи этого захода)

### A. Аккаунт и онбординг
- [ ] Схема: `users` += `email`, `pin_hash`, `avatar_emoji`, `onboarded_at`;
      `user_profile` += `theme_mode`, `reminders_*`, флаги подсказок;
      миграция + регенерация `database.g.dart`.
- [ ] `AuthRepository`: регистрация, вход (PIN необязателен), список
      профилей, удаление; последний профиль — в `shared_preferences`.
- [ ] Riverpod: `ProviderScope`, `dbProvider`, `sessionProvider`,
      `settingsProvider`. Убрать прямой `localUserId` из экранов.
- [ ] Экран **Регистрация** (имя, e-mail по желанию, PIN по желанию,
      эмодзи-аватар).
- [ ] Экран **Вход / выбор профиля**.
- [ ] **Онбординг** (мастер): приветствие → зачем 4 столпа →
      баланс целей (4 ползунка) → минут в день → целевой JLPT →
      стартовый уровень (с нуля / быстрый плейсмент). Пишет `user_profile`,
      ставит `onboarded_at`.

### B. Оболочка, Личный кабинет, Настройки
- [ ] **AppShell** с постоянным `NavigationRail`: Карта, Повторение,
      Статистика, Словарь, Профиль, Настройки. Заменяет `Navigator.push`
      из Карты.
- [ ] **Личный кабинет**: аватар/имя/уровень, сводка (серия, всего карт,
      выучено, % по JLPT), достижения, кнопки правки профиля и выхода.
- [ ] **Настройки**: тема (свет/тьма/системная, с сохранением), дневная
      цель, целевой JLPT, баланс столпов, лимит кандзи/день, уведомления
      (вкл, время, типы), сброс прогресса (с подтверждением), экспорт
      данных в JSON, правка/удаление профиля.

### C. Статистика и серия дней
- [ ] Реальный `currentStreakDays` из `daily_activity`.
- [ ] Экран **Статистика**: календарь активности (~12 недель),
      повторений по дням, точность (из `review_log`), карточки по
      состояниям, разбивка по 4 столпам, сегодня vs цель.
- [ ] Записывать `minutes_spent` и `new_items_learned`, отмечать
      `goal_met`.

### D. Уведомления и подсказки новичку
- [ ] `NotificationService` на `flutter_local_notifications` (Windows).
      Windows не умеет фоновое расписание — поэтому: тост при запуске
      (есть карты / серия под угрозой) + `Timer` пока приложение
      открыто, срабатывающий в заданное время. Опционально — скрипт
      для Планировщика задач Windows.
- [ ] **Coach-marks**: при первом визите на Карту / Повторение /
      Статистику — оверлеи «что за что отвечает». Флаги «показано» в БД,
      кнопка «?» для повторного показа.
- [ ] Тултипы и пустые состояния с пояснениями по всему приложению.

### E. Настоящая дорожная карта (главная цель)
Единый последовательный курс, по которому реально можно выучить N5,
затем каркас N4. Каждый узел — реальная теория + практика + повторение.
- [ ] Пересобрать порядок: Кана → Базовые слова N5 → Кандзи N5 (по 20) →
      Частицы → Грамматика → Аудирование → Веха. Треки кандзи и
      «основной» идут параллельно после каны (уже так), но наполнены.
- [ ] **Грамматика N5**: ~30–40 пунктов (`grammar_points`) с теорией на
      русском, шаблоном, примерами-предложениями. Юниты «Грамматика N5 I/II
      (/III)».
- [ ] **Частицы**: расширить с 4 до ~15 (は/が/を/に/で/へ/と/も/から/まで/
      の/や/ね/よ/か) с теорией и парами-противопоставлениями (は vs が).
- [ ] **Предложения** (`sentences` + `sentence_content_items`): ~150–200
      примеров N5 с фуриганой и переводом, привязанные к словам/частицам/
      грамматике.
- [ ] **Аудирование** через `flutter_tts` (системный голос ja-JP):
      прослушать предложение → выбрать перевод / записать что услышал.
      Фолбэк, если голоса ja-JP нет: текст + ромадзи + пометка.
- [ ] **Базовые слова N5**: юнит(ы) с ~100–150 самыми частотными словами
      (числа, время, семья, глаголы-связки), не только те, что пришли с
      кандзи.
- [ ] Типы упражнений (`exercise_types`): добавить `listening_choice`,
      `reading_recall`, привязать к `pillar` для разбивки прогресса.
- [ ] **N4**: каркас — юниты кандзи N4 (170, уже в БД), заготовки
      грамматики N4, следующая веха.
