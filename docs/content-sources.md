# Источники контента

Реальные, а не выдуманные данные — откуда что взято.

## Кандзи и слова (app/assets/content/kanji.json)

Собрано скриптом (не хранится в репозитории — разовый скрипт сборки,
результат закоммичен как готовый asset) из трёх открытых источников:

- **Список кандзи, частотность, уровень JLPT** —
  [AnchorI/jlpt-kanji-dictionary](https://github.com/AnchorI/jlpt-kanji-dictionary)
  (MIT license).
- **Он/кун-чтения, число черт** — [kanjiapi.dev](https://kanjiapi.dev/)
  (публичное API поверх KANJIDIC2, EDRDG license).
- **Слова-сочетания с русским переводом** — тот же
  jlpt-kanji-dictionary (JMdict-based, с полем `glossary_ru`).

Итог: 2134 кандзи всех уровней JLPT (N5: 80, N4: 170, N3: 370, N2: 380,
N1: 1133 (+1 без официального уровня)) со связанными словами-примерами
(5139 уникальных слов), русские переводы кандзи — краткий ручной
словарь частых английских глоссов KANJIDIC2 (`MEANING_RU` в скрипте
сборки), не полный перевод — то, чего в словаре нет, честно остаётся
на английском, а не выдумывается.

## Кана

Хирагана/катакана (46+46, полный годзюон) — набраны вручную
(`content_seed.dart`), стандартный, не спорный набор знаков.
